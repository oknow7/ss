Features

Everything you need for on-device AI

A complete toolkit for running language models on Android, designed for privacy, performance, and flexibility.

Offline AI

Run language models entirely on-device with no internet connection required. Your AI, available anywhere.

GGUF Support

Compatible with the GGUF model format, enabling efficient quantized inference on mobile hardware.

Voice Assistant

Interact with AI through natural voice conversations. Speak and receive intelligent responses hands-free.

PDF Chat

Upload and analyze PDF documents with AI. Extract insights, summarize content, and ask questions.

Image Analysis

Analyze and understand images with multimodal AI capabilities. Get descriptions and insights from visual content.

Coding Assistant

Get help with code generation, debugging, and explanation. Your portable programming companion.

Multiple Providers

Connect to cloud AI providers alongside local models. Switch between local and cloud inference seamlessly.

Privacy First

Your data never leaves your device when using local models. No tracking, no data collection, no compromises.
