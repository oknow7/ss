Features

Everything You Need

TorrentFlow packs all the essential features for a seamless torrent downloading experience on Android.

Magnet Link Support

Paste magnet links directly or open them from your browser to start downloading instantly.

Torrent File Support

Open .torrent files from any file manager and start downloading with a single tap.

Download Queue Management

Prioritize, pause, resume and reorder downloads with intuitive queue controls.

Bandwidth Controls

Set global and per-torrent speed limits for both upload and download rates.

Real-Time Statistics

Monitor download speeds, ETA, progress and connection health with live updating stats.

Peer Information

View detailed peer lists, connection quality and geo-location data for active torrents.

Tracker Information

Inspect tracker status, announce intervals and seed/peer counts per tracker.

Multi Torrent Downloads

Download multiple torrents simultaneously with smart resource allocation.

Storage Management

Choose download locations, manage completed files and monitor storage usage.

Dark Mode Interface

Beautiful dark theme designed for comfortable use in any lighting condition.

Privacy Focused

No analytics, no tracking and no data collection. Your downloads are your business.
